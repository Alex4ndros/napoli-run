# Napoli Run — Motorini Madness

Un endless runner 3D di Alessandro (Alex4ndros), sviluppato con OpenAI Codex. Corri tra Via Toledo, i Quartieri Spagnoli, il lungomare e Spaccanapoli, evita gli ostacoli e raccogli pizza.

**Gioca gratuitamente** scaricando `NAPOLI-RUN.html` e aprendolo con un browser WebGL. Include l'intero gioco e funziona offline. Il sorgente leggibile con le risorse separate si trova in `dist/`. Comandi e istruzioni sono in [LEGGIMI.md](LEGGIMI.md).
