# Napoli Run — Motorini Madness

Un endless runner 3D di Alessandro (Alex4ndros), sviluppato con OpenAI Codex. Scegli la partenza fra sei luoghi di Napoli, attraversa il mercato di Porta Nolana o Piazza del Plebiscito, schiva i motorini e raccogli pizza. A ogni partita cambia l’ordine delle tappe successive.

**Gioca gratuitamente** scaricando `NAPOLI-RUN.html` e aprendolo con un browser WebGL. Include l'intero gioco e funziona offline. Il sorgente leggibile con le risorse separate si trova in `dist/`. Dopo una modifica a `dist/`, il comando `python3 tools/build_offline.py` rigenera la copia offline. Comandi e istruzioni sono in [LEGGIMI.md](LEGGIMI.md).
